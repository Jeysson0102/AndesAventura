# Andes Aventura - Aplicación Móvil de Turismo y Reservas

Aplicación nativa para Android desarrollada en Kotlin que permite a los usuarios descubrir paquetes turísticos en la Cordillera Blanca, registrar reservas con cálculo automático de costos, autenticarse y geolocalizar puntos de encuentro y destinos finales mediante mapas interactivos con Google Maps.

---

## 1. Requisitos del Entorno
* **Android Studio:** Versión Iguana o superior (recomendado Koala / Ladybug).
* **SDK de Android:** API 24 (Android 7.0 - Nougat) como mínimo y API 34+ como destino.
* **JDK:** JavaVersion 1.8 / 11 configurado en Gradle.
* **Dispositivo:** Emulador Android con Google Play Services o dispositivo físico Android.
